# Large Work Wrap-up

Use this skill only after completing a substantial piece of work. Do not use it
for a trivial edit or before the requested work is complete.

Review the request, changed artifacts, validation results, decisions, and any
unresolved items from the current work. Then answer exactly these two questions:

1. What are you least confident about right now?
2. What's the biggest thing I'm missing about the situation right now, or what don't I realize?

Base each answer on specific evidence from the work. Separate facts from
inferences, state unknowns plainly, and do not invent risks. Do not ask the user
to answer the questions. Output only the two numbered answers.
